# Clini-Tech | كليني تك - نظام إدارة المراكز الطبية والعيادات المتعددة الفروع
> **إدارة أسهل.. رعاية أفضل**

نظام إلكتروني متكامل لإدارة المراكز الطبية والعيادات التخصصية يجمع بين منصتين في بيئة واحدة:
1. **منصة الإدارة والعيادات والأطقم الطبية (Admin & Staff Portal)**: لوحة تحكم ذكية، نظام إدارة فروع وعيادات، صلاحيات متعددة المستويات (RBAC)، ملفات المرضى الإلكترونية (EMR)، العلامات الحيوية (Vitals)، الروشتات الرقمية والتحاليل، وطابور الانتظار المباشر مع شاشة تلفزيون ونغمات نداء.
2. **بوابة المراجعين والكلينت (Client / Patient Portal)**: استعراض الأطباء والتخصصات، مواعيد العيادات، حجز موعد كشف أونلاين برقم دور فوري، وبوابة المريض للاطلاع على مواعيده وروشتاته الطبية وطباعتها.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend**: React 19, Vite, Vanilla CSS Design System (RTL Native), Web Audio API for Chime Bell.
- **Backend**: Node.js, Express.js REST API, JSON File Data Store with Persistence.

---

## 🚀 طريقة التشغيل السريع (Getting Started)

### 1. تشغيل الخادم والـ API (Backend)
```bash
cd backend
npm install
node server.js
```
*يعمل السيرفر على الرابط:* `http://localhost:5000`

### 2. تشغيل واجهة المستخدم (Frontend)
```bash
cd frontend
npm install
npm run dev
```
*يعمل تطبيق الواجهة على الرابط:* `http://localhost:3000`
